# Selected SoundFont

The initial General MIDI bank is **FluidR3_GM.sf2** by Frank Wen and contributors.

- Source and original license files: <https://github.com/pianobooster/fluid-soundfont>
- License: MIT. Preserve the copyright and permission notice when redistributing the bank.
- License notice retained in this project: `COPYING`.
- Expected runtime path: `res://Music/SoundFonts/FluidR3_GM.sf2`

The GM `.sf2` binary is tracked with Git LFS. Ensure Git LFS has downloaded the actual
file before running or exporting the project. Confirm the license notice matches the
exact distributed variant before publishing a build.
